Overview

IQManager replaced a patchwork of spreadsheets, paper forms and legacy desktop apps with one cohesive web platform. The goal was to give every role — engineers, technicians, sales, accounting — a single source of truth, while still feeling fast and unobtrusive for daily work.

The backend is a modular Django monolith with 15+ apps (customers, contracts, tickets, warehouse, timesheets, invoicing, repairs, proposals, file manager, chat, email…) talking to a shared PostgreSQL database. The frontend is a Next.js + Mantine app that consumes the REST API with React Query for caching and optimistic updates.

What I built

I'm the sole developer on the project — design, schema, authentication, data import pipelines, every screen, the deploy pipeline and the customer-facing release notes. New modules ship behind feature flags and the whole stack is reproducible with docker compose up.

Highlights

Modular monolith

15+ Django apps, each owning its slice of domain logic. Easy to grow without microservice overhead.

JWT & role-based perms

Granular permissions per role and per resource, enforced both in DRF and in the Next.js middleware.

Real-time notifications

System-wide notifications with badge counters, mark-as-read, and a unified activity log across modules.

PDF report engine

Templated PDF generation for proposals, repair reports and invoices — branded, paginated, multilingual.

Bulk import / export

Excel and CSV import with row-level validation, dry-run preview and roll-back on error.

myDATA integration

Greek e-invoicing pipeline with retry, signing and audit trail — invoices land in IAPR within seconds.
