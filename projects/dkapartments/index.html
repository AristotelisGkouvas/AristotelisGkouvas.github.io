DK Apartments.

The marketing site for three short-stay apartments 300 m from the Castle of Ioannina. One HTML file, no framework, no build step — bilingual, structured for Google, and built to send a ready guest straight to Booking.com without losing them on the way.

Με λίγα λόγια

Τρία ολοκαίνουργια διαμερίσματα στο κέντρο των Ιωαννίνων, με 9.1 στη Booking, χρειάζονταν ένα site που να τα δείχνει όπως τους αξίζει — και να στέλνει τον επισκέπτη στην κράτηση σε δύο κλικ.

Ελληνικά και αγγλικά, φωτογραφίες ανά διαμέρισμα, οδηγός για την πόλη, φόρμα διαθεσιμότητας που ανοίγει κατευθείαν τη Booking. Μηδέν μηνιαία συνδρομή για τον ιδιοκτήτη.

Visit live site

Overview

Most guests find a small property on Booking.com, then Google its name to see whether it is real. That second visit is the whole job of this site: confirm the place is as good as the 9.1 says, answer the questions the listing does not, and hand the guest back to the booking page before they drift.

Three units — a studio and two one-bedroom apartments with very different interiors — each get their own photo set, feature list and floor area. Around them sits everything a first-time visitor to Ioannina asks about: what to see, how far things are on foot, house rules, cancellation terms and an FAQ.

One file, on purpose

The site is a single HTML document with its CSS and JavaScript inlined — around 80 KB of code plus photography, served through Cloudflare. No framework, no bundler, no CMS. For a property owner that means nothing to update, nothing that expires and no monthly bill; for the guest it means the page is painted before a framework would have finished downloading.

Bilingual without a backend

Every translatable string carries a data-i18n key and the English dictionary lives in the same file. The switch is instant, the URL (?lang=en) is shareable, and the hreflang and og:locale:alternate tags tell Google and social crawlers that both versions exist.

Highlights

Availability hand-off

The form validates dates client-side (check-out must follow check-in) and then opens the property's Booking.com page — the site never pretends to be a booking engine it is not.

Bilingual, shareable

data-i18n keys and an inline English dictionary; ?lang=en is a real URL with matching hreflang alternates, so both languages are indexed.

Per-apartment photo sets

Forty-odd photographs organised by unit and lazy-loaded, with a crossfading hero slideshow — the site sells the interiors, so the interiors get the bandwidth.

The city, in walking minutes

Castle, lake, island, Dodoni, Perama cave, Zagori — plus a distance list from the front door, because "central" means nothing until you say how many minutes.

Structured for Google

A LodgingBusiness JSON-LD block, canonical and locale tags, Open Graph with a real photo — so the rich result and the WhatsApp preview both look like a hotel, not a blank card.

Zero dependencies, zero bill

No framework, no build, no CMS, no plugins to patch. One file behind Cloudflare; the owner's only recurring cost is the domain.
